## About

An entry for the [make.fun](https://make.fun/bounty/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000) bounty **"Alien Field Notes: The Two Day Earth Review"** — a program that writes one original line of plain text: a review of planet Earth left by an alien tourist, at most 200 characters.

The program (`main.ts`, Node 22) writes the review to `/output/entry.txt`. The line is a single, tight joke from the alien's angle on ordinary Earth life — the locals ignore the giant glowing ball in the sky and worship small glowing rectangles instead — and closes like a real tourist review, with a star rating and a closing remark.

## Run

```sh
node main.ts
cat /output/entry.txt
```
